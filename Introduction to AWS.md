### Introduction to AWS Cloud  

#### **What is AWS?**  
Amazon Web Services (AWS) is a cloud computing platform that provides on-demand computing resources and services. It allows individuals and businesses to host applications, store data, manage databases, and deploy code without managing physical servers.  

#### **When and Why Was AWS Created?**  
- **Launched:** AWS was officially launched in **2006** by Amazon.  
- **Reason:** Amazon needed scalable and efficient infrastructure to run its e-commerce business. Later, they realized other businesses also needed similar cloud computing resources, leading to AWS becoming a commercial cloud service provider.  

#### **Uses of AWS**  
AWS is widely used for:  
1. **Hosting Websites & Applications** – Deploy web apps and APIs using services like EC2, S3, and Lambda.  
2. **Cloud Storage** – Store and retrieve large amounts of data with services like S3 and EBS.  
3. **Database Management** – Host relational and NoSQL databases like RDS and DynamoDB.  
4. **Machine Learning & AI** – AWS provides AI/ML services like SageMaker.  
5. **Big Data Processing** – AWS services like AWS Glue and Redshift handle large-scale data processing.  
6. **Serverless Computing** – AWS Lambda allows running code without managing servers.  
7. **DevOps & CI/CD** – Automate deployments using AWS CodePipeline, CodeDeploy, and CodeBuild.  
8. **Networking & Security** – Secure cloud environments with services like IAM, VPC, and CloudFront.
