### **AWS Services**  
AWS provides a wide range of cloud services categorized into different domains. Here are the most important ones:  

---

### **1. Compute Services (Processing Power)**
- **Amazon EC2 (Elastic Compute Cloud)** – Virtual servers to run applications.  
- **AWS Lambda** – Serverless computing; runs code without managing servers.  
- **Amazon Lightsail** – Easy-to-use virtual private servers (VPS) for small applications.  
- **AWS Elastic Beanstalk** – PaaS (Platform as a Service) to deploy applications quickly.  
- **Amazon ECS (Elastic Container Service)** – Runs Docker containers.  
- **Amazon EKS (Elastic Kubernetes Service)** – Manages Kubernetes clusters.  

---

### **2. Storage Services (Data Storage)**
- **Amazon S3 (Simple Storage Service)** – Scalable object storage.  
- **Amazon EBS (Elastic Block Store)** – Persistent block storage for EC2.  
- **Amazon EFS (Elastic File System)** – Managed file storage.  
- **Amazon Glacier** – Low-cost archival storage.  
- **AWS Storage Gateway** – Hybrid cloud storage solution.  

---

### **3. Database Services**
- **Amazon RDS (Relational Database Service)** – Managed databases like MySQL, PostgreSQL, and SQL Server.  
- **Amazon DynamoDB** – NoSQL key-value database.  
- **Amazon Aurora** – High-performance relational database.  
- **Amazon Redshift** – Data warehousing for analytics.  
- **AWS Database Migration Service (DMS)** – Migrate databases to AWS.  

---

### **4. Networking & Content Delivery**
- **Amazon VPC (Virtual Private Cloud)** – Isolated cloud networks.  
- **AWS Route 53** – Scalable Domain Name System (DNS).  
- **AWS CloudFront** – Content Delivery Network (CDN) for fast content delivery.  
- **AWS Elastic Load Balancing (ELB)** – Distributes traffic across multiple instances.  

---

### **5. Security & Identity Management**
- **AWS IAM (Identity and Access Management)** – User access control.  
- **AWS Shield** – DDoS protection.  
- **AWS WAF (Web Application Firewall)** – Protects web applications from attacks.  
- **AWS KMS (Key Management Service)** – Manages encryption keys.  

---

### **6. Developer & DevOps Tools**
- **AWS CodeCommit** – Managed Git repositories.  
- **AWS CodeBuild** – Builds and tests code automatically.  
- **AWS CodeDeploy** – Automates code deployments.  
- **AWS CodePipeline** – CI/CD automation.  
- **AWS CloudFormation** – Infrastructure as Code (IaC).  
- **AWS CloudWatch** – Monitoring and logging.  

---

### **7. AI & Machine Learning**
- **Amazon SageMaker** – Machine learning model training and deployment.  
- **AWS Rekognition** – Image and video analysis.  
- **AWS Lex** – Chatbot service (like Alexa).  
- **AWS Polly** – Text-to-speech conversion.  

---

### **8. Analytics & Big Data**
- **AWS Glue** – ETL (Extract, Transform, Load) for data processing.  
- **Amazon Athena** – SQL queries on S3 data.  
- **Amazon Kinesis** – Real-time data streaming.  
- **Amazon QuickSight** – Business intelligence and visualization.  

---

### **9. Internet of Things (IoT)**
- **AWS IoT Core** – Connect and manage IoT devices.  
- **AWS Greengrass** – Run IoT applications locally on devices.  

---

### **10. Game Development**
- **Amazon GameLift** – Multiplayer game server hosting.  

---

### **11. Blockchain & Quantum Computing**
- **Amazon Managed Blockchain** – Create and manage blockchain networks.  
- **Amazon Braket** – Quantum computing experiments.  

---

### **12. Hybrid Cloud & Edge Computing**
- **AWS Outposts** – Extends AWS services to on-premise data centers.  
- **AWS Snowball** – Physical data transfer device for large data migration.  

---
